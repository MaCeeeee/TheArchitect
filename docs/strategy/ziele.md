# Oberste Ziele — der Anker für Entscheidungen

**Version 1.0 · 2026-08-30** · Geändert wird hier nur bewusst: Versionsbump + Begründung im Änderungslog, nie als Nebeneffekt eines Tickets.

**Zweck:** Jedes Entscheidungsticket (Label `Decision`) benennt je Option die **Zielwirkung** gegen diesen Katalog — Pre-Flight Stufe 3. Eine Entscheidung ist immer *für* ein Ziel; dieser Katalog macht benennbar, für welches — und auf wessen Kosten.

## Gebrauchsregeln

- **Je Option eine Zeile, nur die Nicht-Neutralen:** `Zielwirkung: ↑G1 (halber Satz) · ↓G4 (halber Satz)`. Was ein Ziel weder stärkt noch kostet, wird nicht genannt — der Block soll den Trade-off zeigen, nicht Vollständigkeit simulieren.
- **Keine gewichtete Summe.** Der Katalog rechnet keinen Sieger aus; er zwingt nur, zu benennen, welches Ziel über welches gestellt wird. Entschieden wird von Menschen (Asilomar #16).
- **Schlussblock:** Die gewählte Option übernimmt ihre Zeile — „**Zielwirkung:** stärkt G_, kostet G_ — bewusst."
- **Drift-Diagnose:** Opfern Entscheidungen wiederholt dasselbe Ziel, gehört der Befund auf die Betting Table — Ziel streichen oder Kurs korrigieren. Beides ist legitim; nur stilles Weiteropfern nicht.

## Bewusst NICHT aufgenommen
